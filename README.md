# Sistema-reservas-1
Sistema de reservas para la empresa Software FJ, el cual será una aplicación funcional en programación.
Este proyecto corresponde al desarrollo de un sistema de reservas implementado en Python, orientado a la gestión de diferentes servicios como:- Reserva de salas- Alquiler de equipos- Asesorías especializadasEl sistema permite validar disponibilidad, calcular costos y registrar eventos mediante el módulo `logging`, aplicando conceptos de programación orientada a objetos, manejo de excepciones y modularización del código, objetivos, Implementar un sistema modular en Python.- Aplicar herencia y polimorfismo, Gestionar excepciones personalizadas, Registrar eventos y errores mediante logs, Simular procesos de reservas y cálculo de costos.

Funcionalidades
Reserva de Sala

Permite:
Registrar salas
Validar disponibilidad
Calcular costos adicionales

Incluir servicios adicionales:
Aire acondicionado
Internet
Videobeam

Alquiler de Equipos
Permite:
Registrar equipos tecnológicos
Validar disponibilidad de inventario
Gestionar préstamos de equipos

Asesorías
Permite:
Registrar asesorías especializadas
Calcular costos por horas
Validar disponibilidad del servicio

Tecnologías Utilizadas

Python 
Vissual studio code
Programación Orientada a Objetos (POO)

Logging
Manejo de excepciones

Manejo de Logs
El sistema utiliza el módulo logging para registrar:
Inicio de la aplicación
Validaciones exitosas
Errores y excepciones

Procesos realizados

Los registros se almacenan en:
logs.txt

Manejo de Excepciones
El proyecto implementa excepciones personalizadas para controlar errores como:
Datos inválidos
Servicios no disponibles
Disponibilidad insuficiente

Esto mejora la estabilidad y control del sistema.

Ejecución del Proyecto
1. Clonar el repositorio
git clone https://github.com/Unad-Grupo-440/Sistema-reservas-1.git

2. Ingresar a la carpeta
cd Sistema-reservas-1

3. Ejecutar el programa
python main.py

Resultados Esperados
El sistema mostrará:

Información de reservas
Validaciones de disponibilidad
Cálculo de costos
Mensajes de error controlados
Registro de eventos en logs
